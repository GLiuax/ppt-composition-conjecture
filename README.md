# PPT map composition with a qubit

This repository contains the current PRL manuscript and its Supplemental
Material in a single LaTeX source file.

- `qubit_anywhere_prl.tex` contains the manuscript and Supplemental Material.
- `qubit_anywhere_prl.bib` contains the bibliography.
- `qubit_anywhere_prl.pdf` is the compiled manuscript.

Compile the source with

```sh
latexmk -pdf qubit_anywhere_prl.tex
```
